# 南雍待办 · 本地版使用说明

> 完全脱离云服务（Coze / Supabase）的本地运行版本。数据存在你自己电脑的本地文件里，Coze 合同到期后依然可以完整使用。

## 📦 环境要求

- **Node.js 18+**（推荐 20 或更高）
- **pnpm**（包管理器）

## 🚀 快速启动

```bash
# 1. 安装依赖（首次运行）
pnpm install

# 2. 配置（可选）
# 复制 .env.local.example 为 .env.local，修改 JWT 密钥
# AI 解析默认配置也可在 .env.local 中设置，或在网页「设置」页单独填写

# 3. 启动开发服务器
pnpm local:dev
# 或生产模式
pnpm local:build && pnpm local:start

# 4. 浏览器打开
# http://localhost:3000
```

## 🗄 数据存储

所有数据保存在 **`data/db.json`** 文件中（首次运行时自动创建）：

```json
{
  "users": [],   // 用户（邮箱+密码哈希）
  "tasks": [],   // 任务
  "tags": [],    // 标签
  "task_tags": [] // 任务-标签关联
}
```

- **备份**：直接复制 `data/db.json` 即可备份全部数据
- **迁移**：把 db.json 复制到新电脑的项目目录下即可恢复
- 数据目录可用环境变量 `LOCAL_DB_PATH` 自定义位置

## 👤 用户系统（本地版特性）

- 注册即生效，**无需邮箱验证**（本地版不发送邮件）
- 密码使用 PBKDF2 加密存储（非明文）
- 登录态 7 天有效（JWT）
- **多用户数据互相隔离**（每个用户只能看到自己的任务）

## 🤖 AI 智能解析

本地版**不依赖 Coze 的 AI 接口**，直接调用 OpenAI 兼容 API：

1. 打开「设置」页 → AI 设置
2. 填写：Base URL（如 `https://api.openai.com/v1`）、API Key、模型名
3. 或编辑 `.env.local` 配置默认值（`AI_BASE_URL` / `AI_API_KEY` / `AI_MODEL`）

> 兼容 OpenAI、智谱（GLM）、文心（ERNIE）、豆包（Doubao）等所有 OpenAI 兼容格式的服务。

**课程表导入不需要 AI**：教务系统课程表（HTML 或文本）由内置的确定性解析器处理，100% 准确且免费。

## 🔄 与云端版的关系

| 对比项 | 云端版 (coze.site) | 本地版 |
|--------|-------------------|--------|
| 运行环境 | Coze 云 | 你自己的电脑 |
| 数据存储 | Supabase 云数据库 | 本地 data/db.json |
| 登录 | 邮箱+密码 | 邮箱+密码（无邮件验证）|
| AI 解析 | Coze 内置模型 | 你自己配置的 API Key |
| 依赖 | Coze 平台 | 仅 Node.js |

**建议**：平时用云端版（方便手机访问），本地版作为"保险"定期备份。两者代码同源，功能一致。

## ❓ 常见问题

**Q: 忘记密码怎么办？**
本地版暂不支持邮件找回。可以联系管理员，或手动编辑 `data/db.json`（找到对应用户，删除后重新注册；密码哈希不可逆，无法直接查看）。

**Q: 能在手机上用吗？**
可以！在同一局域网内，用 `http://电脑IP:3000` 访问（需要电脑防火墙放行 3000 端口）。也可以部署到自己的云服务器上。

**Q: 数据会不会丢？**
数据保存在本地文件，定期备份 `data/db.json` 即可。比云服务更安全——不依赖任何第三方平台的存续。
